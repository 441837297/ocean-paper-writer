# Revision Brief

Use this task-local template after Strategy and before Prose. A confirmed brief is a closed
scientific contract: Prose may improve expression but must not change its scientific content.

```markdown
## Revision ID
REV-<unit>-<number>

## Status
Frozen

## Unit
<section, paragraph, figure, or response item>

## Current function
<what the old text does>

## New function
<what the revised unit must accomplish>

## Keep
<facts, logic, and connections that remain>

## Remove / supersede
<old claims, metrics, wording, or emphasis that must not return>

## Verified new evidence
<authorized results, numbers, figures; or none>

## Argument sequence
<authorized order of claims and evidence>

## Claim boundary
<what must not be claimed, inferred, or compared>

## Connection
<only an evidence-supported connection to adjacent prose; or none>

## Acceptance criteria
<conditions for Verify to return PASS>
```

If new evidence changes the scientific decision, return to Strategy, revise the brief, and freeze
the new version before Prose resumes.
