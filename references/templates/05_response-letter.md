# Response Letter

> Before drafting, classify each comment using the strategy framework in
> `references/review/response-letter.md`: MINOR_EDIT / CLARIFY / ADD_ANALYSIS /
> CORRECT / BOUNDARY. Apply the two universal rules: use `you`/`your` throughout;
> at most one brief acknowledgment per comment.
>
> Use one persistent draft for each revision round. Keep the reviewer comment
> verbatim. For the final Word layout, use the bundled response-letter DOCX
> template: comments and responses in black, revised manuscript text in blue,
> locations in blue italics. The author applies final Track Changes manually.
