# Ocean Science Domain Expression

## Purpose

This module provides ocean-science-specific expression guidance for English manuscript writing.
It is loaded during the 04 writing stage when drafting any section that involves
domain terminology, quantitative description, or physical interpretation.

Default output is English-only manuscript prose.

## Safe expression patterns

| Use case | Pattern | Evidence needed |
|----------|---------|-----------------|
| spatial pattern | [Variable] shows [pattern] in [region], with [quantitative contrast] between [sub-regions]. | Figure with spatial map or section |
| temporal variability | [Variable] exhibits [period] variability of [magnitude], with [phase/trend]. | Time series or Hovmöller diagram |
| vertical structure | The vertical profile of [variable] reveals [feature] at [depth range]. | Vertical profile or section plot |
| process interpretation | This pattern is consistent with [process], as supported by [diagnostic]. | Diagnostic variable or literature |
| model-observation comparison | The model reproduces the observed [pattern], with discrepancies in [region/season]. | Side-by-side comparison figure |
| uncertainty statement | Uncertainty in [variable] is estimated as [value/range] based on [method]. | Uncertainty quantification |

## Claim boundary reminders

- **A spatial pattern is not a physical mechanism.** Mechanism requires process-based diagnostics.
- **Correlation is not causation.** Co-variability does not establish causal direction.
- **Model output is not observation.** Always label the source.
- **A regional result is not a global conclusion.** State the study domain explicitly.
- **Climate relevance is not climate-change attribution.** Relevance means the topic matters
  for understanding climate; attribution means the change is formally linked to a forcing.

## Avoid generic phrases

| Avoid | Better direction |
|-------|------------------|
| The ocean is changing. | Specify which property, where, by how much, and over what period. |
| This has important implications. | State the specific implication and the mechanism. |
| Our results provide new insights. | State what was learned that was not known before. |
| The results are reasonable. | Provide quantitative validation or physical reasoning. |
| More research is needed. | State the specific diagnostic, dataset, or experiment needed. |
| The data clearly shows... | State the quantitative finding; let the evidence speak. |

## Section-specific expression tips

**Methods:** past tense, passive or active (journal-dependent), precise parameter values.

**Results:** present tense for established facts, past for specific study actions.
Lead with the finding, not the figure reference.
Example: "SST increased by 0.3°C per decade" not "Figure 3 shows SST increasing".

**Discussion:** present tense for interpretation, past for literature comparison.
Verbs matched to evidence strength (suggests / indicates / is consistent with).

**Introduction:** present tense for established knowledge, past for prior studies.
The gap statement must cite literature.

**Conclusion:** present tense for findings, cautious modals for implications (may / could).
No new evidence.

**Abstract:** present tense for the finding, past for the approach.
Self-contained; check journal word limit.
